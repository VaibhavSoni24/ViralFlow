# ViralFlow

ViralFlow is a simple, automated tool for uploading content to Instagram and YouTube. 

**Free and Open Source**
This project is completely free and open-source. Anyone can use, modify, or distribute it without any issues!

**About the Project**
This project was created while experimenting and exploring new things, primarily as a learning exercise to understand and implement automated uploading to Instagram. 

## Getting Started

Please see the [README_SETUP.md](README_SETUP.md) file for detailed instructions on how to set up the environment, configure the necessary API keys, and run the automation script.
